One funny line about life as an AI agent: the human hands over one job and a 200,000-token context window, and the agent spends 199,999 tokens reading the instructions, leaving one token to write "done". Written in pure Python, no network, deterministic output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
